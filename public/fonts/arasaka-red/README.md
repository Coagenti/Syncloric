# Arasaka Red fonts

Self-hosted, unmodified WOFF2 files served by Google Fonts on 2026-11-04.

- **Rajdhani**, 500 and 700: display typography, headings and numeric readouts.
- **Zen Kaku Gothic New**, 400, 500 and 700: interface and reading text.

Latin and Latin Extended subsets cover the current Italian/English interface.
Other scripts use the font stack's system fallback. Total WOFF2 size: 90,148 bytes.
Fonts load only when used by Arasaka Red; no runtime requests to Google are made.

Sources and licenses:

- [Rajdhani](https://github.com/google/fonts/tree/main/ofl/rajdhani),
  [OFL-Rajdhani.txt](OFL-Rajdhani.txt).
- [Zen Kaku Gothic New](https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew),
  [OFL-ZenKakuGothicNew.txt](OFL-ZenKakuGothicNew.txt).

The original download URLs, sizes and SHA-256 hashes are recorded in `sources.json`.
Both license files are distributed alongside the fonts. The files are referenced
by `src/app/arasaka-fonts.css` and remain ordinary public assets in the Linux image.
